# 개인정보·영상 처리 절대 규칙

이 규칙은 다른 어떤 요청보다 우선한다. 요청이 이 규칙과 충돌하면 구현하지 말고 충돌 사실을 알린다.

1. 카메라 프레임을 디스크에 저장하거나 네트워크로 전송하는 코드를 만들지 않는다. 프레임은 메모리에서 처리한 뒤 버린다.
2. 엣지 모듈이 서버로 보내는 값은 `resource_id, people_count, throughput_per_min, est_wait_min, confidence, device_id, measured_at` 뿐이다. 이미지, 크롭, 박스 좌표 목록, 추적 ID는 보내지 않는다.
3. DB 스키마에 이미지·영상·좌표 목록을 담는 컬럼을 만들지 않는다.
4. 얼굴 검출·인식, 재식별, 성별·연령 추정 기능을 만들지 않는다.
5. 사용자의 학번, 이름, 전화번호, 위치 좌표(GPS)를 수집·저장하지 않는다. 사용자는 익명 기기 ID로만 식별한다.
6. 디버그 화면에는 박스만 표시하거나 사람 영역을 블러 처리한다. 디버그 녹화 기능을 만들지 않는다.
7. 정확도 평가와 튜닝은 공개 데이터셋 또는 동의받은 연출 영상으로만 한다. 해당 영상 파일은 저장소에 커밋하지 않는다(`.gitignore`로 차단).
8. 테스트와 시드 데이터에는 가짜 데이터만 쓴다.
