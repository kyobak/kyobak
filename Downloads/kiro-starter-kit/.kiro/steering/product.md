# 제품 개요

## 무엇을 만드나
ERICA 캠퍼스 대기 통합 서비스(가칭). 한양대학교 ERICA 학생이 줄이 생기는 곳의 현재 상태와 예상 대기시간을 한 화면에서 보고, 자기 차례가 되면 알림을 받는 모바일 웹앱(PWA)이다.

## 프로젝트 성격
- AI+X 공학융합프로젝트(2026 가을) 팀 굳건(4인)의 한 학기 프로토타입이다. 상용 서비스가 아니다.
- 최종 데모데이는 2026년 11월 30일 주간이다. 완성도보다 "끝까지 동작하는 수직 흐름"을 우선한다.

## 사용자
- 기숙사생(세탁실), 셔틀·학식 이용 학생, 관리자 역할의 조교.
- 로그인 없이 익명 기기 ID로 식별한다.

## 핵심 개념: 대기 자원(resource)
모든 대상은 하나의 `resource` 모델로 다룬다.
- kind: `laundry` | `space` | `shuttle` | `cafeteria` | `parking`
- 상태 공급원(source): `vision`(영상 인원 계수) | `report`(사용자 제보) | `qr`(QR 체크인) | `admin`(관리자 입력) | `crawl`(크롤링)
- 새 기능은 새 화면을 따로 만드는 것이 아니라, 새 kind 또는 새 source 어댑터를 추가하는 방식으로 확장한다.

## 기능과 우선순위
| 우선순위 | 기능 |
|---|---|
| Must | 통합 대시보드(자원별 상태, 예상 대기시간) |
| Must | 영상 인원 계수 + 처리율 기반 대기시간 추정 (연출 영상, 라이브 웹캠) |
| Must | 학식 메뉴와 혼잡도, 셔틀 다음 출발 시각과 줄 길이 |
| Must | 세탁기 QR 사용 시작, 남은 시간, 가상 대기열, 내 차례 푸시 알림 |
| Must | 영상 데이터가 없거나 신뢰도가 낮으면 제보·예측값으로 대체 표시 |
| Should | 셔틀 탑승 가능 회차 계산, 시간대별 혼잡도 예측, 오픈스페이스 QR 체크인, 학식 한 곳 현장 파일럿 |
| Could | 주차장 잔여석(관리자 입력·목업), 세탁기 진동 센서, 영어 UI, 관리자 자원 등록 화면 |

## 핵심 계산
- 예상 대기시간(분) = 줄 인원 ÷ 분당 처리 인원. 처리 인원이 0이면 "계산 불가"로 표시한다.
- 셔틀 탑승 가능 회차 = ceil((줄 인원 + 1) ÷ 버스 정원). 학기 중 입석 금지를 가정한다.
- 인원 수 자체보다 대기시간이 사용자에게 보여줄 주된 값이다.

## 차별점
기존 학생 서비스는 메뉴·시간표·도착정보를 나열한다. 이 서비스는 "지금 가면 몇 분 기다리나"와 "내 차례가 되면 알려준다"에 집중한다.

## 범위 밖 (구현하지 말 것)
- 강제력 있는 세탁기 예약 (가상 대기열만 구현)
- 학번·포털 로그인, 결제
- 얼굴 인식, 개인 재식별, 성별·연령 추정
- 사용자 GPS 수집
- 영상 저장, 클라우드 비전 AI로 프레임 전송
