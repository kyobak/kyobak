# 브리프 03: laundry-queue (기숙사 세탁실 가상 대기열)

## 목적
세탁기·건조기 사용 상황과 남은 시간을 보여주고, 빈 기기가 생기면 대기 순번대로 알린다. 강제력 있는 예약은 만들지 않는다(실물 우선 원칙).

## 사용자 스토리
- 기숙사생으로서, 세탁실에 내려가기 전에 빈 기기가 있는지 알고 싶다.
- 기숙사생으로서, 기기에 붙은 QR을 찍어 사용 시작을 알리고 끝날 때 알림을 받고 싶다.
- 기숙사생으로서, 모든 기기가 사용 중이면 순번을 등록하고 내 차례에 알림을 받고 싶다.

## 요구사항 초안 (EARS)
- REQ-LAU-01: WHEN 사용자가 세탁기 QR을 스캔하고 코스를 선택하면, 시스템은 해당 기기를 '사용 중'으로 바꾸고 종료 예정 시각을 표시해야 한다.
- REQ-LAU-02: WHEN 종료 예정 시각이 되면, 시스템은 사용 시작자에게 수거 알림을 보내야 한다.
- REQ-LAU-03: IF 종료 예정 시각 후 10분이 지나도 수거 확인이 없으면, THEN 시스템은 기기를 '수거 대기'로 표시하고 알림을 한 번 더 보내야 한다.
- REQ-LAU-04: WHEN 대기열이 있는 기기가 '사용 가능'으로 바뀌면, 시스템은 1순위 대기자에게 5초 이내에 푸시 알림을 보내야 한다.
- REQ-LAU-05: IF 호출된 대기자가 5분 안에 사용을 시작하지 않으면, THEN 시스템은 해당 순번을 만료하고 다음 대기자를 호출해야 한다.
- REQ-LAU-06: 시스템은 한 기기 ID가 같은 세탁실에 대기 순번을 하나만 가지도록 해야 한다.
- REQ-LAU-07: WHEN 사용자가 대기를 취소하면, 시스템은 뒤 순번을 한 칸씩 당겨야 한다.
- REQ-LAU-08: 시스템은 앱 화면에 "기기는 먼저 온 사람이 우선이며 순번은 안내용"임을 표시해야 한다.

## 데이터
`resources(kind=laundry)`, `status_events`, `queue_tickets`, `push_subs`

## 범위 밖
공식 예약, 결제, 진동 센서(05-extras), 기숙사생 인증.

## 완료 기준
QR 흐름으로 사용 시작 → 타이머 → 종료 알림이 동작한다. 대기열 호출·만료·취소 단위 테스트가 통과한다. iOS에서 홈 화면 추가 후 알림이 오고, 불가하면 화면 내 배너로 대체된다.
