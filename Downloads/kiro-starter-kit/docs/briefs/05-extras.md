# 브리프 05: extras (Should·Could 기능)

11주차 중간 데모 이후 Must 기능이 안정되면 진행한다. 필요한 항목만 골라 스펙을 만든다.

## 오픈스페이스 (Should)
- REQ-SPC-01: WHEN 사용자가 오픈스페이스 입구 QR을 스캔하면, 시스템은 체크인 상태로 기록하고 재실 인원을 1 늘려야 한다.
- REQ-SPC-02: IF 체크인 후 4시간 동안 체크아웃이 없으면, THEN 시스템은 자동 체크아웃 처리해야 한다.
- REQ-SPC-03: 시스템은 단과대별 오픈스페이스의 재실 인원과 수용 인원 대비 비율을 표시해야 한다.

## 혼잡도 예측 (Should)
- REQ-PRD-01: 시스템은 요일·시간대별 과거 vision_metrics와 reports로 자원별 예상 혼잡도를 하루 한 번 계산해 predictions에 저장해야 한다.
- REQ-PRD-02: 시스템은 예측값에 모델 버전을 함께 저장해야 한다.

## 관리자 입력과 주차장 (Could)
- REQ-PRK-01: WHEN 관리자가 주차장 잔여석을 입력하면, 시스템은 입력 시각과 함께 대시보드에 표시해야 한다.
- REQ-ADM-01: 시스템은 관리자 코드로 인증된 사용자만 자원 등록·수정 화면에 접근하게 해야 한다.

## 세탁기 진동 센서 (Could)
- REQ-LAU-20: WHEN 센서가 일정 시간 이상 진동을 감지하면, 시스템은 해당 기기를 '사용 중'으로 표시해야 한다.
- 센서는 ESP32 + 가속도 센서, 기기 상판 부착, 전원선 비접촉 방식. 기숙사 허가가 있을 때만.

## 영어 UI (Could)
- REQ-I18N-01: 시스템은 한국어와 영어 전환을 지원해야 한다.
